# Agent Adapters（实验）

本目录用于记录同一份用例在不同个人智能体框架下的执行差异。

- 原始用例仍以 `usecases/*.md` 为准。
- Adapter 不复制完整用例，只描述“这个 agent 下要怎么改”。
- 当前第一批适配目标是 Hermes；未来可以继续增加 `claude-code/`、`cursor/`、`openhands/` 等目录。
