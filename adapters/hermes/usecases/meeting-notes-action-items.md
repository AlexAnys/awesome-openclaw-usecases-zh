# Hermes 适配：会议纪要与待办自动化

> 这是 [会议纪要与待办自动化](../../../usecases/meeting-notes-action-items.md) 的 Hermes 执行差异说明。完整背景、痛点和原始提示词请先阅读原用例。

## 一句话适配结论

`partial`。如果用户提供会议转写文本/录音转写结果，Hermes 可直接生成纪要和待办；如果要自动从飞书妙记、腾讯会议、钉钉拉取并创建任务，则需要平台账号和 adapter。

## 概念映射

| OpenClaw | Hermes | 备注 |
|---|---|---|
| 飞书妙记/腾讯会议/钉钉 | Lark CLI / 导出文件 / 平台 API | 第一批适配先支持用户提供文本 |
| 创建待办 | Hermes Reminders/Linear/Notion/飞书 CLI | 外部写入前确认 |
| 定时跟进 | `cronjob` | 可定时提醒未完成 action items |

## Hermes 下的执行差异

1. **最小路径**：用户上传或粘贴会议转写文本，Hermes 生成纪要、决策、行动项。
2. **平台路径**：飞书妙记可结合 Lark CLI 搜索/读取；腾讯会议/钉钉需另行确认 API 或导出方式。
3. **任务创建**：默认输出待办草稿，不直接写入飞书/Linear/Notion。
4. **隐私处理**：敏感会议建议本地处理，不发送到公开频道。

## 最小验证

```text
下面是一段会议转写文本。请生成：1）三句话摘要；2）关键决策；3）行动项表格（负责人/截止时间/状态）；4）需要追问的信息。不要创建任何外部任务。
```

期望：生成结构化纪要和待办草稿，无外部写入。

## 已知限制 / 风险

- `privacy`：会议内容可能包含商业机密或个人信息。
- `external_write`：创建任务、发群消息前必须确认。
- 平台拉取能力依赖 OAuth、企业权限和 API 可用性。
